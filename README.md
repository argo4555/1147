# 1147 Detailing — демо-сайт

Демо-версия сайта детейлинг-центра **1147 Detailing** (Москва, Маломосковская ул., 14, паркинг, −1 этаж, круглосуточно) для показа клиенту с телефона.

- **Публичная часть** (`/`): первый экран, витрина услуг с фильтрами и «Что входит», прайс по классам авто, «до/после» и галерея, FAQ, контакты с маршрутом в Яндекс Картах, быстрая запись в два шага.
- **Демо-панель менеджера** (`/admin/`): тестовые заявки, счётчики и фильтры по статусам, поиск, смена статуса, восстановление демо-данных.

Стек: HTML, CSS, vanilla JS (ES-модули), без сборки и без прикладного бэкенда. Nginx только раздаёт файлы. Ключи и секреты не нужны.

## Запуск

Без Docker, из корня проекта (нужен Python 3):

```
python -m http.server 8080 --directory site
```

Открыть http://localhost:8080/ и http://localhost:8080/admin/.

В Docker:

```
docker build -t detailing1147-demo .
docker run --rm -p 8080:80 detailing1147-demo
```

Nginx отдаёт `/` → главная, `/admin/` и прямое обновление `/admin/` → панель, `/admin` → редирект на `/admin/`, неизвестный путь → 404. Ссылки внутри сайта относительные, поэтому страница работает и в корне домена, и из `/admin/`.

## Как работает тестовая заявка

- Запись: шаг 1 — направление (или «Нужна консультация»), услуга, класс авто, день и желаемое время по Москве (необязательно, вариант «Уточнить время» есть всегда); шаг 2 — проверка, цена по прайсу, ориентировочная длительность и тестовый профиль.
- Имя и телефон не запрашиваются: используется фиксированный тестовый профиль «Тестовый клиент, +7 (900) 000-00-00». Пример поля телефона показан только для чтения.
- Заявка сохраняется в `localStorage` этого же сайта (ключи с префиксом `d1147.`): номер, услуга, класс, дата и время визита (как строка МСК + ISO с `+03:00`, без пересчёта часового пояса при показе), профиль, время создания, статус. Повторное нажатие не создаёт дубль.
- Никаких запросов на сервер и уведомлений нет. Время не бронируется, менеджер заявку не получает — это сказано в окне записи и на экране успеха.
- Если `localStorage` недоступен (приватный режим, запрет cookies), показывается понятное сообщение, экран успеха не рисуется.
- Демо-заявки (4 шт.) создаются в браузере один раз; «Восстановить демо-данные» удаляет только ключи `d1147.*`.

**Ограничение демо:** заявки видны только в том браузере и на том устройстве, где созданы. Чтобы заявки с телефонов клиентов доходили до менеджера на другом устройстве, нужен боевой приём заявок (сервер или интеграция с CRM/мессенджером) — это следующий этап.

## Проверки

```

```

`tools/check.mjs` запускает Chrome или Edge в headless-режиме (Node 22+, без npm-зависимостей) и проходит сценарии через DevTools Protocol. Для Docker-контейнера: `BASE=http://127.0.0.1:8080 node tools/check.mjs`.

Последний прогон (25.11.2026): **85 из 85 проверок пройдено** и на `python -m http.server`, и на Nginx с конфигурацией из `nginx/default.conf` (подробно — `docs/check-report.json`, прогон через Nginx). Что проверяется:

- HTTP: `/`, `/admin/`, `/admin` → редирект, 404, `robots.txt`; служебные файлы (README, Dockerfile, tools, nginx, оригинал логотипа) не отдаются.
- 390 px: «Полировка кузова» → «Что входит» → «Записаться» → 3 класс, завтра 15:00 → шаг 2 (цена 20 000 ₽, «от 3 ч») → двойной клик по «Создать тестовую заявку» (одна заявка) → «Открыть в демо-панели» → заявка выделена и первая, услуга/класс/время совпадают → статус «Связались» сохраняется после перезагрузки.
- Запись без услуги (ошибки у полей), «Нужна консультация» + «Не знаю класс» + «Уточнить время», «Назад» без потери выбора, «Вернуться к услугам».
- Прайс: класс 2 меняет цены, запись из строки переносит услугу и класс, поиск с пустой выдачей и «Сбросить фильтры», категории, «Ещё N позиций».
- Клавиатура: Tab/Shift+Tab не выходят из окна, Escape закрывает окна и меню и возвращает фокус; галерея (стрелки, Escape, кнопка); «до/после» с клавиатуры и касанием без перетаскивания.
- Нижняя панель скрыта при открытой записи; шапка и кнопка окна записи закреплены; landscape 844×390 для записи и меню; якоря не уходят под шапку.
- Ширины 320, 360, 390, 430, 768, 1280, 1440 px — без горизонтальной прокрутки на главной и в панели; прямая ссылка `/#contacts` открывает нужный блок.
- Зоны нажатия ≥ 44×44, поля ввода ≥ 16 px, ошибок в консоли и сети нет.
- Панель: обновление по событию `storage` из другой вкладки, пустое состояние и сброс фильтров, поиск по номеру, восстановление демо-данных (чужие ключи не тронуты).
- Недоступный `localStorage`: сообщение в записи и в панели.
- Без JavaScript: адрес, телефон, список услуг и базовый прайс есть в HTML.

Замеры (headless Chrome, эмуляция телефона 390×844, кеш отключён):

- Начальная передача главной: **376 КБ** через Nginx с gzip и **490 КБ** без сжатия (python http.server); без карты и внешних виджетов, бюджет 750 КБ.
- Главное фото загружается сразу (WebP, `srcset`/`sizes`, отдельный кроп для телефона), остальные — лениво; шрифты локальные, с `font-display: optional` и preload.
- Сдвиг макета при загрузке (CLS): **0**.

Проверялось только в эмуляции Chrome (мобильный режим и касания). На реальном iPhone/Safari сценарий не проходился — перед показом стоит открыть сайт на телефоне.

## Сценарий презентации (45–60 секунд)

1. Открыть сайт на телефоне: первый экран — «Детейлинг и автомойка в Москве», адрес, «Записаться» и «Посмотреть цены»; внизу всегда «Записаться» и «Позвонить».
2. «Услуги» → карточка «Полировка кузова» → «Что входит»: состав, длительность, варианты с ценами.
3. «Записаться: Полировка кузова» → выбрать 3 класс — цена 20 000 ₽ подставляется из прайса → «Завтра», 15:00 → «Далее».
4. Шаг 2: итог, тестовый профиль, подпись «Демо · заявка сохранится в этом браузере» → «Создать тестовую заявку».
5. «Открыть в демо-панели» → новая заявка выделена наверху → сменить статус на «Связались» → обновить страницу: статус сохранился.
